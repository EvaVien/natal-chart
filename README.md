# Натальная карта

Статичный сайт: вводите дату, время и город рождения — получаете колесо натальной карты,
положения планет по знакам и домам, аспекты и гороскоп на текущий момент.
Все расчёты идут в браузере, ключи и сервер не нужны.

## Запуск

Откройте `index.html` в браузере. Нужен интернет только для поиска города (геокодер Open-Meteo).
Шрифты лежат в папке `fonts/`, сторонние сервисы для оформления не нужны.

## Что считается

- **Планеты:** Солнце, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Плутон;
  отметка ретроградности (℞).
- **Асцендент и дома:** система Плацидус; на широтах выше 66° автоматически равные дома.
- **Аспекты:** соединение, секстиль, квадрат, тригон, оппозиция — списком и линиями на колесе.
- **Время неизвестно:** карта строится на полдень, Асцендент и дома скрываются,
  а если Луна в тот день сменила знак — показываются оба варианта.
- **Неоднозначный город:** если найдено несколько мест, предлагается выбрать нужное.

## Точность

Формулы П. Шлитера с поправками на взаимные возмущения Юпитера, Сатурна и Урана;
для Плутона — приближённая формула (годна для 1800–2100). Проверено по Swiss Ephemeris
на датах 1900–2100: Солнце и планеты — в пределах ~0,03°, Луна — ~0,04°,
Асцендент, МС и вершины домов — ~0,01°. Для бытовой астрологии этого с запасом достаточно.
Расчёт работает для дат с 1900 года.

## Файлы

| файл | что внутри |
|---|---|
| `index.html` | разметка трёх экранов: форма, загрузка, результат |
| `script.js` | астрономические формулы, дома, аспекты, SVG-колесо, интерфейс |
| `style.css` | оформление: цвета и шрифты в `:root`, форма, колесо, вкладки |
| `fonts/` | Prata, Onest и набор астрологических значков (Noto Sans Symbols) |

Астрология — способ посмотреть на себя со стороны, а не научный прогноз.

## Шрифты и лицензии
