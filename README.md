# Эфемерида — натальная карта

Статичный сайт: вводите дату, время и город рождения — получаете колесо натальной карты, положения планет по знакам и домам,
аспекты и краткое описание «неба сейчас». Чистые HTML, CSS и JavaScript без сборки и зависимостей. Расчёты идут в браузере.

**Демо:** <https://evavien.github.io/natal-chart/> (ожидаемый адрес GitHub Pages для этого репозитория;
проверьте в *Settings → Pages*, что публикация включена).

> Астрология — способ посмотреть на себя со стороны, а не научный прогноз. Проект считает астрономические положения; их толкование — культурная традиция.

## Возможности

- Солнце, Луна и планеты от Меркурия до Плутона, Асцендент, МС, 12 домов (Плацидус), аспекты, ретроградность (R).
- SVG-колесо **и** текстовые списки планет и аспектов: данные не доступны только через картинку.
- Неизвестное время рождения: карта строится на полдень; Асцендент, МС и дома не определяются, у Луны — только знак
  (или два знака, если в тот день она его сменила), градусы остальных планет показываются как «около N°».
- Уточнение города, если мест несколько (учитывается регион и страна: можно писать «Уфа, Башкортостан»).
- Сохранение и ссылка **только по явному нажатию**; печать и сохранение в PDF средствами браузера.
- Раздел «Сегодня»: транзиты быстрых планет к вашей карте на текущий момент.

## Запуск и разработка

Нужен только браузер. Сайт можно открыть как `index.html`, но проще через любой статический сервер
(так же работает GitHub Pages):

```bash
python3 -m http.server 8000     # затем http://localhost:8000/
```

Для поиска города нужен интернет (геокодер Open-Meteo). Шрифты лежат в `fonts/`, внешних зависимостей для оформления нет.

```bash
node --test          # то же самое: npm test (Node 20+)
```

| `tests/chart.test.js` | `computeChart()` целиком: известное/неизвестное время, смена знака Луной, DST, будущее, 1900, высокие широты, «Сегодня» |

CI (`.github/workflows/tests.yml`) запускает `node --test` на каждый push и pull request.

## Архитектура

Один файл `script.js`, разделённый на зоны с явными границами (комментарии `// ===== N. … =====`).
Зоны 1–4 не касаются DOM и тестируются напрямую (`module.exports`); DOM-код вынесен в зону 6 и выполняется только в браузере.

1. **ASTRONOMY** — орбитальные элементы Шлитера, возмущения Юпитера/Сатурна/Урана, Плутон, Асцендент, МС, дома.
2. **TIMEZONE** — `resolveLocal()`: «обычное / невозможное / неоднозначное» локальное время; границы суток.
3. **GEOCODING** — `geocode()` с таймаутом и отменой, проверка ответа, ранжирование. **3b:** сохранение и ссылки (чистые функции).
4. **CHART CALCULATION** — `computeChart()`, аспекты, транзиты «Сегодня».
5. **UI & RENDERING** — SVG колеса, декоративное колесо.
6. **BOOTSTRAP & UI LOGIC** — форма, состояния, доступность, сохранение, печать.

`script.js` намеренно не разбит на модули: проект остаётся без сборки, а границы зон достаточно ясны. Если файл вырастет, зоны 1–4 естественно выносятся в отдельные файлы.

## Точность и ограничения

Формулы П. Шлитера (Paul Schlyter) с поправками на взаимные возмущения; Плутон — приближённая формула, справедливая для 1800–2100.
**Измеренное расхождение со Swiss Ephemeris** (11 дат 1900–2099, разные широты; `node --test` проверяет эти допуски):

| величина | наибольшая ошибка | допуск в тестах |
|---|---|---|
| Солнце, Меркурий, Венера, Юпитер, Сатурн, Уран, Нептун, Плутон | до 0,03° | 0,06° |
| Марс | 0,043° | 0,06° |
| Луна | 0,067° | 0,10° |
| Асцендент, МС, куспиды домов | до 0,01° | 0,03° |

- **Диапазон дат.** Форма принимает даты с **1 января 1900** по сегодня. Будущие даты отклоняются. Формулы протестированы до 2099 года.
- **Астрономия.** Тропический зодиак, геоцентрические положения, без нутации и аберрации; для бытовой астрологии этого достаточно (ошибка Луны ≈ 4 угловые минуты).
- **Дома.** Только Плацидус. На широтах выше 66° Плацидус неопределён, поэтому используются **равные дома** (и это указано в интерфейсе).
  Асцендент на высоких широтах проверяется правилом «к востоку от МС» (без него формула давала ошибку на 180° у каждой третьей точки выше ~65°; регрессия закреплена тестом по 120 случайным точкам).
- **Время рождения.** Если локального времени не существовало (перевод часов вперёд) — расчёт не выполняется, пользователь видит ошибку.
  Если время повторялось дважды (перевод назад) — пользователю предлагается выбрать нужный из двух моментов; молча ничего не выбирается.
- **Часовые пояса** берутся из базы IANA вашего браузера (Intl); для давних дат результат зависит от версии базы в браузере.
  Поясом места считается тот, что вернул геокодер; для редких мест он может быть неточным — проверяйте.
- **Неизвестное время.** Градусы Луны не показываются; для остальных планет — «около N°»; Асцендент, МС и дома недоступны. Аспекты транзитов к такой Луне не считаются.
- **«Сегодня».** Лёгкий раздел: транзиты считаются на абсолютный момент (UTC); он показывается в часовом поясе устройства и в UTC.
  Участвуют только Луна, Солнце, Меркурий, Венера, Марс, Юпитер и Сатурн; Уран, Нептун и Плутон не учитываются. Это не научный прогноз.
- **Не реализовано:** другие системы домов, астероиды и лунные узлы, синастрия, транзиты внешних планет.

## Приватность

- Расчёт целиком в браузере. Аналитики, трекеров, cookies и реклам нет; сервера у проекта нет.
- **Наружу уходит одно:** название города (до запятой) — в сервис геокодинга [Open-Meteo](https://open-meteo.com/). Дата и время рождения не отправляются.
- `localStorage` используется **только после нажатия «Сохранить карту»** и хранит минимум: дату, время и место. Расчёт не сохраняется. Удаляется кнопкой «Удалить сохранённые данные».
  Данные, которые оставила предыдущая версия сайта (ключ `natal_chart_last`), без согласия удаляются при открытии.
- Ссылка «Поделиться картой» **содержит дату, время и место рождения** в адресе и создаётся только по нажатию «Скопировать ссылку», после предупреждения.
  При открытии по ссылке параметры проходят строгую проверку и сразу убираются из адресной строки.
- Данные из URL, localStorage и ответов геокодера считаются недоверенными и попадают в страницу через `textContent`.

## Доступность

Семантическая разметка, `lang="ru"`, skip-link, единый `:focus-visible`, подписи полей через `for`, ошибки связаны через `aria-describedby` и `aria-invalid`,
глобальный `role="status"` (поиск города, выбор, расчёт, готово, ошибка), фокус на первое ошибочное поле / на варианты города / на заголовок результата,
вкладки с клавиатурой (стрелки, Home, End), `prefers-reduced-motion`. Колесо дублируется текстовыми списками.

## Структура репозитория

```
index.html  style.css  script.js     — сайт
fonts/                               — Prata, Onest, Astro (значки)
assets/social-preview.png            — превью для соцсетей (исходник: assets/social-preview.html, tools/make-social-preview.js)
tests/                               — node:test + tests/fixtures + tests/tools/make-fixtures.py
tools/smoke.py                       — опциональная проверка в браузере
.github/workflows/tests.yml          — CI
```

Превью для соцсетей пересобирается так: `node tools/make-social-preview.js`, затем снимок `assets/social-preview.html` в 1200×630.
